# 🚀  Obstacle Avoidance for Serial Manipulators (Master Thesis) 

Real-time obstacle avoidance algorithms for serial-chain robotic manipulators, implemented in C++ and tested on the Franka Emika Panda platform.

---

## 📌 Features

- Static, dynamic, and self-collision avoidance
- Real-time distance and proximity computation
- Kinematic modeling with modified Denavit–Hartenberg parameters
- Modular and extensible C++ design
- CMake-based build system
